手順（1製品ずつ）：
1. https://www.amazon.co.jp/dp/<ASIN> を開く（ASIN は各行の先頭の10文字）。
2. ページ上部の SiteStripe で「リンクを作成」（または「商品リンク」）を押し、「画像」タブを選ぶ。
3. 表示された HTML コードを、加工せずに全文コピーする（<a href=... から最後の <img ... /> まで）。
4. コードの中に tag=suuchigakari-22 が入っていることを確かめる。
