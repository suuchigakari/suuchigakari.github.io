## 申請の手順

1. サイトを公開する（`README.md` の「公開する」を参照）。**申請フォームに入れる URL は、実際に開ける状態**にしておく。
2. <https://affiliate.amazon.co.jp/> から申し込む。Amazon の買い物用アカウントがあればそのまま使える。
3. 入力するもの：氏名・住所・電話番号、サイトURL、サイトの内容（カテゴリ・トピック・集客方法）、希望のトラッキングID（例 `yourname-22`）。
4. 電話番号の確認（自動音声で PIN が読み上げられる）を通すと、**仮アカウント**が発行される。
5. 発行されたトラッキングIDを `site.config.json` の `associateTag` に設定する。ページ上部のサンプル警告が消えれば反映済み。
6. 仮アカウントのままリンクを設置し、**180日以内に3件の適格販売**を発生させる。ここで初めて本審査に進む。
7. 本審査を通過したら、支払い方法（銀行口座など）を設定する。

## 落としやすい点

- **自己購入・家族の購入は適格販売に数えられない。** 意図的に自分で買って3件を作ると、規約違反として否認される。
- 180日を過ぎて3件に届かないとアカウントは閉鎖される。**再申請は可能**なので、記事を増やしてから出し直す。
- 価格は掲載しない（PA-API または Amazon が提供する価格リンク以外での価格表示は不可）。本サイトは価格帯のみ表示している。
- 商品画像はPA-APIまたは公式ウィジェット経由のみ。画像を保存して貼らない。
- カスタマーレビューや星評価の転載も不可（Creators API 経由を除く）。
- ステマ規制（景品表示法）対応として、広告であることが分かる表示を読者が認識できる位置に置く。開示文をヘッダーとフッターの両方に出しているのはこのため。

## 申請時に書く「サイトの説明」の下書き

> 用途がはっきりしていて数値で比較できる道具を、メーカー公式の仕様表だけを使って比較する個人サイトです。
> 機内持ち込みキャリーケース、ベビーゲート、クーラーボックス、寝袋、圧力鍋、キッチンスケールなど13ジャンルについて、
> 「表示の数字が何を意味しているか」（3辺合計と各辺の上限、保冷力の表記の違い、最小表示と計量精度など）を整理し、
> 読者の条件（開口幅・身長・必要な容量など）を入れると対応する製品を判定できる比較表を掲載しています。
> 実際に使用したレビューではなく、公式に公開された数値の比較です。集客はオーガニック検索が中心です。
